# CleanZone — search visibility, 6.10.2026

## Аудит и изменения

Стек: обычный HTML/CSS/JS, GitHub Pages, существующий серверный обработчик отдельно. Контент доступен без исполнения JavaScript. Framework, CMS и сборщика изначально не было; добавлена проверка и подготовка статической сборки через `npm run build` (Python 3, без зависимостей). GitHub Pages продолжает публиковать существующие файлы из корня. `npm test` — существующие 23 теста. Рекламные теги, обработчик Telegram, формы, прайс и анимационные JS не изменены.

До изменения: robots разрешал всех; главная, robots, sitemap и Banino отвечали 200 с Server: GitHub.com, без X-Robots-Tag. HTTP-проверки с user agents OAI-SearchBot, Claude-SearchBot, Claude-User, Googlebot и Bingbot также давали 200. Это проверка доступности с нашей сети, а не доказательство прохода всех IP реальных роботов. Доступа к WAF/firewall/CDN-настройкам нет; их внутренние правила не менялись. Признаков отдельного Cloudflare в полученных заголовках нет.

Созданы четыре самостоятельные страницы услуг: `/pranie-tapicerki-gdansk/`, `/pranie-kanapy-gdansk/`, `/pranie-materaca-gdansk/`, `/pranie-naroznika-gdansk/`. У каждой уникальные title/description/H1/canonical/OpenGraph, полезный собственный текст, подготовка к визиту, актуальные цены соответствующих услуг, CTA в первом блоке, телефон, реальные примеры до/после (на фото канапа, не выдаётся за матрас), FAQ и ссылки. Фото в первом блоке подписано как визуализация. Существующие шесть страниц окрестностей сохранены, добавлены условия сушки и переходы к услугам. Новых шаблонных страниц городов не создавали.

Бренд в HTML/метаданных и schema унифицирован как CleanZone; стилизованный логотип сохранён. Главная поясняет основной регион обслуживания. В JSON-LD один LocalBusiness на страницу с устойчивым `@id`, телефоном, логотипом, подтверждёнными Instagram/Google-профилем и девятью зонами обслуживания. Адреса, координат, наград и фиктивных часов/рейтинга не добавляли. Добавлены Service, BreadcrumbList (видимый путь) и FAQPage, совпадающий с видимыми вопросами. LocalBusiness без подтверждённого адреса не следует считать гарантированно подходящим для Google LocalBusiness rich results. FAQPage не обещает расширенный результат для коммерческого сайта.

Все поисковые роботы имеют одинаковые исключения для технических каталогов, thank-you и партнёрского предложения; GPTBot и ClaudeBot блокируются отдельно как training crawlers. Robots — добровольное правило обхода, не защита секретов и не контроль доступа. Частная информация не добавляется в статическую публикацию. Не меняли ключи, безопасность или доступ к backend.

Sitemap теперь содержит 11 индексируемых страниц. Noindex партнёрской страницы и thank-you сохранён; они исключены из карты. Страница партнёров остаётся доступной по существующему меню. Новые ссылки на услуги добавлены компактно в существующий блок сведений о регионе, без SEO-стены текста в первом экране.

## Bing и вспомогательные файлы

IndexNow по официальному протоколу: публичный файл подтверждения владения в корне; `npm run indexnow` проверяет опубликованный ключ и отправляет только sitemap URL. Выполнять после публикации изменений. Ответ 200/202 означает приём уведомления, не индексирование и не позицию. Ключ IndexNow — предназначенный для публикации токен владения сайтом, не API-ключ аккаунта. Bing Webmaster Tools и его отчёты пока не проверены: нужно подключить/проверить ресурс, можно импортировать подтверждение GSC через штатный интерфейс Bing.

llms.txt не добавлялся: в проверенных официальных рекомендациях OpenAI/Anthropic нет требования к нему или основания объявлять его фактором ранжирования. Google также прямо указывает, что новые AI text files не нужны. Основная работа направлена на публичный HTML, понятные услуги, ссылки, разметку и реальные внешние подтверждения.
